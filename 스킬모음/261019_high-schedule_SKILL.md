# 고등 일정 짜기 (261019)

## 한 줄 요약
학교·학생의 시험일과 속도를 받아 **월·수·토 DAY 표**(주차별 3칸)로 바꾸고, 선생님이 OK 하면 앱의 `ROAD`·`VIS`·`EXAMD` 에 그대로 옮긴다.

## 필요한 것
- 시험일(기간), 시작일, 교과서 과 순서, 모의고사 회차 수, 학생이 정한 속도.
- 모의고사 범위 지문이 확정됐는지(안 됐으면 "준비 중" 칸으로 둔다).

## 하는 일
1. 수업일은 **월·수·토 고정**(DOFF=[0,2,5]). 한 주 = DAY 3개. 요일이 달라도 DAY 순서대로 하면 된다("추천일"로만 표기).
2. 회차 수를 정한다. 교과서 한 과 = 덩어리(part) N개 = N회. 덩어리는 문장 수가 비슷하게.
3. 순서: 교과서 과들 → 모의고사 회차 → **최종점검**(마지막 약 1주, 3~4회). 최종점검 문구는 모든 학교 **"틀린 문제 · 약한 유형 골라 풀기"**.
4. DAY 표를 만들어 선생님께 보여 준다 (주차 | 월 | 수 | 토). 학생이 속도를 바꾸면 표부터 다시 쓴다.
5. OK 되면 index.html 의 `ROAD`(주차 큰 흐름), `VIS`(주차별 DAY 3개: `{L|T|D|F:n,t,s,x}`), `EXAMD`(시험 기간), `SEC` 를 채운다. L=교과서 4과, T=교과서 3과, D=모의고사, F=최종점검.
6. 시험 기간은 달력에 빨간색. 시험 전날이 남으면 그 DAY 는 비워 두고 선생님께 묻는다.

### 예시 표 (261019 확정 3가지)
| 학교 | 순서 |
|---|---|
| 청석고1·금천고1 | 3과 4회 → 4과 4회 → 모의고사 10회 → 최종점검 3회 (시험 청석 12/7~11, 금천 12/7~10) |
| 주성고1 이시온 | 10/19·21 4과 1~2회 → 10/24 3과 1회 → 10/26·28·31 3과 2~4회 → 11/2~11/21 모의고사 9회 → 11/23~ 최종점검 4회 (시험 12/1~4 가정) |
| 청석고2·금천고2 | 4과 4회 → 3과 4회 → 모의고사 10회 → 최종정리 3회 |
| 주성고2 | 4과 3회 → 모의고사 1회독(하루 3지문) → 2회독(하루 6지문) → 최종점검 |

## 끝났다는 신호
- 달력에서 월·수·토에만 점이 있고, 시험일이 빨갛고, 마지막 DAY 가 시험 전에 끝난다.
- 선생님이 표를 보고 OK 했다.

## 하지 말 것
- 요일 선택 기능, "밀림" 표시, 잠금: 만들지 않는다(학생이 아무 DAY나 먼저 해도 된다).
- 모의고사 내용이 없는데 있는 척 채우지 않는다("내용은 준비 중이에요").
- 합의 전에 활동 페이지 제작을 시작하지 않는다. 일정은 자주 바뀐다.
