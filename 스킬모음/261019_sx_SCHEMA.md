## 최상위
{
 "set": "geumcheon-3",            // 단원 id
 "title": "3과 …",               // 화면 제목에 쓰는 단원 이름
 "lesson": true,                  // 교과서 단원이면 true(구역들이 한 글의 앞뒤), 모의고사 모음이면 false(지문마다 독립)
 "hw": {"ko":"L3-sunko","abc":"L3-sunabc","mun":"L3-sunmun","blank":"L3-blank"},   // 옛 페이지의 GK.hw('...') id를 그대로 (없으면 생략)
 "passages": [ 구역/지문 ... ]
}

## passage (구역 또는 지문) — 문장 수 n
{
 "id": "z1", "label": "Bill Traylor ① 삶과 그림의 시작", "taught": null | true | false (모의고사만),
 "gist": "한글 한 줄 요약 (English 표어)",          // lesson=true일 때 '앞 내용/뒷 내용'으로 접혀 보이는 한 줄
 "modes": ["ko","abc","mun","blank"],               // 가능한 앱. abc는 n>=7, mun은 n>=5 이어야 함
 "nums": [5,6,7,...],                               // 화면에 보일 원래 문장 번호(교과서 문장 번호). 모의고사는 1..n
 "en": [n개], "ko": [n개],                          // 영어/자연스러운 한글 해석, 옛 페이지 값 그대로(마침표 포함)
 "key": [[conn, line] × n],
 "why": [n개, why[0]=""],
 "theme": "빈칸용 본문 엑기스 한두 문장(옛 blank 페이지의 theme)",
 "link": [bool × (n-1)],   // link[i]=true → i+1번 문장에 앞 문장과 이어지는 뚜렷한 단서(연결어·지시어)가 있어 끊어도 순서가 정해진다
 "ins": [i, ...],          // 문장삽입으로 낼 수 있는 문장 번호(인덱스, 1..n-1). 앞 문장과의 단서가 분명한 것만
 "blanks": [ {"s": 문장인덱스, "ans": "정답(문장 안 연속 부분 문자열)", "ans_ko": "정답 뜻", "opts": [{"en","ko"}×4 오답], "clue": "…"} ... ]
}

## 가장 중요한 내용 규칙 (학생이 읽고 본문을 또 한 번 본 효과가 나게)
1. key[i] = [conn, line]
   - conn: 문장 앞 연결어/담화표지 "However(그러나)", "For example(예를 들어)" 형태(영어+괄호 한글 뜻). 없으면 "".
   - line: 한글 한 줄(약 35자 이내) + 맨 끝에 본문에서 그대로 뽑은 짧은 영어 표어를 괄호로. 예) "개를 두려워한 이유: 노예 감시·사냥에 쓰임 (used to watch and hunt slaves)"
     영어 표어는 그 문장 본문에 실제 있는 2~6단어. 모든 문장에 반드시 하나. 한글만 있는 줄은 불합격.
2. why[i] (i≥1) = "i번 문장이 왜 바로 i-1번 뒤에 와야 하는가" 단서 1~2문장. 반드시 그 한 쌍에 딱 맞는 내용으로:
   - 연결어/지시어/대명사/관사(the, this, these, such, they, it, also, however, for example, as a result …)가 앞 문장의 무엇을 받는지,
     또는 시간 순서·원인→결과·일반→예시·주장→반론 같은 논리 관계를 말한다.
   - 영어 단서는 (영어 뜻) 형태로 병기: "'In contrast(반면)'는 앞에 반대되는 내용이 와야 쓸 수 있어요. 앞 문장이 개에 대한 두려움(fear of dogs)을 말했으니 …"
   - 어느 단락에나 들어갈 일반론("흐름상 자연스러워요") 금지. 문장마다 달라야 한다. 문장 번호는 화면 번호(nums)가 아니라 쓰지 말고 "앞 문장"으로 표현.
   - 해요체, 한 쌍당 100자 안팎(최대 160자).
3. gist, theme, clue도 한글 + (English 표어). blank clue = "이 빈칸이 왜 이런 내용인지": 앞뒤 문장이 무엇을 말하므로 빈칸은 어떤 내용이어야 하는지 1~2문장, 정답 근거가 되는 영어 표어를 (영어 뜻)으로 병기.
4. 구역 나누기(lesson=true): 한 구역은 7~13문장의 자연스러운 의미 덩어리(옛 blank 페이지의 sections를 기본으로). 구역 순서 = 본문 순서.
5. link/ins: 옛 페이지의 안전하게 끊는 자리(zones/SETS/WIN, INS_Q 등)를 참고하되 새 규칙으로 직접 판단. link가 true인 자리 = 뚜렷한 단서가 있어 안전하게 끊을 수 있는 곳, false = 단서가 약해 끊으면 모호한 곳.
   ins 후보는 연결어/지시어/대명사 단서로 위치가 하나로 정해지는 문장(구역당 최소 3개, 가능하면 절반 이상).
6. 한글 해석(ko)은 옛 페이지 그대로 옮기고 임의로 고치지 않는다. 영어도 마찬가지. 구두점 포함 글자 하나까지 같게.
7. blanks: 옛 blank 페이지의 문항을 모두 옮긴다(문항 수 줄이지 말 것). ans는 en[s] 안에 그대로 들어 있어야 한다.
