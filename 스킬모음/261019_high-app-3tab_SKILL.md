# 고등 학생 앱 틀 조립 (261019)

## 한 줄 요약
학교 폴더 하나(`h/<학교>/`)에 **3탭(원문·답안지·오늘의 학습), 달력형 첫 화면, 오답 노트, 최종점검**을 갖춘 앱을 만든다. 학생이 자기 폰에서만 진도를 관리한다. 상세 설계는 `261019_학생앱_3탭_설계.md`(추가 확정 1~3 포함).

## 필요한 것
- 일정 표(261019_high-schedule), 활동 페이지(4단계)·답안지(5단계) 결과, 견본 폴더 `h/jusung-go1/`(고1)·`h/jusung-go2/`(고2).

## 하는 일
1. 견본 폴더를 복사해 학교 폴더를 만든다. 학교 이름·아이콘(고1 호박색 주황 / 고2 파랑 / 고3 보라, 가운데 학년 뱃지+학교명)을 바꾼다.
2. index.html 의 표를 채운다: `ROAD`·`VIS`·`DOFF`·`EXAMD`(일정), `SEC`(교과서 4과·모의고사·교과서 3과·최종점검의 활동 주소), `ACT`, `KEYS`(답안지), `CNT`(문항 수 실측, 0이면 칸 숨김).
3. `parts.js`: 지문 id와 덩어리(`PARTS.L4/L3/mock`, `names`). 모든 활동 페이지가 `?part=N` 을 받는다.
4. 화면 규칙: 
   - 탭 안에는 제목·설명 문구를 넣지 않는다. 용어는 "교과서 3과/4과".
   - 달력은 월화수목금토일(일요일 맨 끝), 점 표시, 선택한 날 파란 원, 시험일 빨강.
   - 활동 순서 8가지 고정(어휘 → TF → 어법선택 → 한글 순서 → ABC 순서 → 문장삽입 → 어색한 곳 → 빈칸추론). 최종점검 DAY 는 "틀린 문제 다시 풀기" / "약한 유형 골라 풀기" 두 칸.
   - "완성 도장" 같은 표현 금지. 담백한 문구.
5. 오답 노트: `wrong.js`·`wrong.html` 복사(학교명 치환) + 각 활동 페이지에 훅. 틀리면 자동 담김, 빼기는 학생이 두 번 눌러서. `?wrong=1&part=N` 은 담긴 문제만 다시 풀기. 유형 칩으로 약한 유형만 골라 새 문제로 풀기(`?pick=type`).
6. 원문 탭(고1): 보기 방식 버튼 **[좌본문 우해석 / 주요 문장 성분 분석 / 동사형 말하기]**. 주요 문장 성분 분석 = 핵심 7문장 분석(기본)·(심화) 3과·4과 링크. 비어 있는 "문법 분석"·"주요 문장 15"는 자료가 생기기 전까지 뺀다. 동사형 말하기는 3과·4과 동사형 말하기 연습 앱(`../c2-<출판사>-34/?hub=3|4`)으로 이동 + "학원에서 꼭 시험으로 봐요" 안내. 고2는 `L4/dongsa-test.html`.
7. 랜덤 문항(2회독·최종점검용): 교과서 전체 유형에서 20문항씩 랜덤 회차. 한 번 나온 문제는 풀이 소진 전까지 다시 나오지 않고(최소 2~3회차 겹침 없음), 풀이 소진되면 새로 섞는다. `?mix=1` 모드가 오답 노트 훅(`WN.ids`)을 재사용하고 `mix.html` 에서 회차를 시작·이어푼다. 매번 새로 생성되는 유형(ABC 순서)은 풀에서 제외.
8. 기록: 학생 기기 localStorage(`vhp:<학교>`, 오답 `vhw:<학교>`, 랜덤 `vhmx:<학교>`). 서버·코드 없음. 학습 기록 카드와 "기록 옮기기"로 다른 기기 이동.
