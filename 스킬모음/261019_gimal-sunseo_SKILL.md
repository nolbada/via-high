# 261019 개정 요약
- 문장 단위 영어 순서배열(sunseo-mun의 (가))은 없앴다. sunseo-mun.html 은 이제 **문장삽입 전용**이다(파일 이름은 학생 링크·숙제 기록 때문에 그대로).
- 네 앱(sunseo-ko / sunseo-abc / sunseo-mun / blank)이 모든 학교에서 같은 엔진 h/common/sx.js + h/common/sx.css 를 쓴다. 각 단원 폴더에는 sx-data.js(데이터 한 개)와 얇은 html 4개만 있다. 엔진을 고치면 모든 학교가 한 번에 바뀐다.
- 목적: 어떤 활동이든 풀고 나면 본문을 한 번 더 본 효과. 그래서 해설은 "왜?"와 "전체 흐름 속 위치"를 보여 준다.

## 시작 전에 필요한 원본
- 단원 본문 영어·한글 해석(문장 번호 포함), 빈칸 문항(정답·한글 뜻·오답 4개).
- 구역 나누기 기준(교과서는 의미 단락, 7~13문장씩).
이 외의 재료(연결어, 단서 why, 영어 표어, clue)는 새로 쓴다. 규격은 261019_sx_SCHEMA.md.

## 해설 설계(확정)
1. **ABC**: 제출하면 정답 순서, 그리고 '왜 이 순서일까요?' — 주어진 글→(B), (B)→(A), (A)→(C) 이음새마다 그 자리의 연결어·지시어 단서 한 줄(why). 아래에 '전체 흐름 속 내 위치': 단원이면 앞/뒤 구역은 한 줄 요약(gist)으로 접고, 푼 구역은 문장마다 [연결어 칩] 한글 한 줄 (영어 표어)로 펼치고, 이번에 푼 범위를 옅은 노란 박스로 감싼다. 정답 순서대로 놓고 첫 문장 앞에 (A)(B)(C) 꼬리표.
2. **문장삽입**: 주어진 문장 + 본문 6문장에 ①~⑤(시험처럼). 선택 후 '제출하기'. 해설은 '왜 ○번 자리?' — 앞 문장과의 단서, 뒤 문장과의 단서(why[j], why[j+1]) + 노란 박스 흐름(주어진 문장 행은 진한 노랑). 매번 다른 문제(창 위치·자리 5개 뽑기·정답 번호 랜덤).
3. **한글 순서배열**: 같은 방식(이음새 3개 + 흐름).
4. **빈칸추론**: 기존의 간결한 해설(엑기스·정답 영어·해석·나머지 보기 해석만) 유지 + '이 빈칸은 무슨 내용일까요?'(clue) 한 줄 + 빈칸 문장 앞뒤를 노란 박스로 감싼 흐름.
5. 한글 해석 보기/닫기 버튼, 이어풀기, 한 문제씩 제출→확인→다음, 매번 다른 문제 표기는 기존 규칙 그대로.
- 학생 화면 문구는 담백하게. 한글 옆에는 (English 표어)를 붙여 해석력도 키운다.

## 데이터에서 중요한 것
- key[i] = [연결어, 한글 한 줄 (영어 표어)] — 영어 표어는 그 문장에 실제 있는 2~6단어.
- why[i] = 그 문장이 왜 바로 앞 문장 뒤인지. 문장쌍마다 달라야 하고 지시어가 가리키는 대상을 말한다. 일반론 금지.
- link[i]=true → i+1번 문장에 앞 문장(i번)과 이어지는 뚜렷한 단서(연결어·지시어)가 있어, 그 자리에서 끊어도 순서가 하나로 정해진다. false → 대명사 등이 애매해 끊으면 순서가 모호하다 (true가 많을수록 문제를 많이 낼 수 있다). ins: 문장삽입으로 낼 수 있는 문장(연결어/지시어 단서가 분명한 것).
- 구역이 7문장 미만이면 abc에서 빠지고 5문장 미만이면 문장삽입에서 빠진다(modes로 조절).

## 새 학교·새 단원 만들기
1. 단원 데이터 JSON 작성(규격: 261019_sx_SCHEMA.md) → python3 validate.py 로 검증.
2. fidelity.py 식으로 영어·해석·빈칸이 원본과 글자까지 같은지 대조.
3. build_all.py 의 UNITS 에 단원 추가 → 빌드 → h/<학교>/<과>/ 에 sx-data.js + 4개 html 생성, 목록(index.html) 라벨 갱신.
4. e2e.py 로 모든 앱을 눌러 보며 해설(.why .ctx .hlbox)이 나오는지 확인.
- 빌더 스크립트: 저장소 스킬모음/261019_sx_빌더/ (mkpage.py, build_all.py, validate.py, fidelity.py, e2e.py, SCHEMA.md, 엔진 원본 sx.js·sx.css).
- 숙제 기록: DATA.hw = {ko,abc,mun,blank} 의 GK.hw id(옛 id 그대로 유지). 한 세트를 끝까지 풀면 1회 기록.
- 저장 키: 이어풀기 sx-res:<경로>, 안 쓴 문제 기록 sx-used:<세트>:<앱>. 이전 형식(gk-res:…)과 섞이지 않는다.
