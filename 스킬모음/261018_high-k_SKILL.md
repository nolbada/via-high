# H-K코스 앱 만들기 (high-k)

H-K코스 = Key(핵심 잡기). V시그널 E단계 '오늘 7문장' 방식 그대로 뼈대부터 분석한다. 내부 이름은 'H-K코스'. 서열 표현(상위권·B반 등) 금지. 학생 화면 표기는 아래 '이름 표기' 규칙을 따른다.

## 이름 표기 (학생 화면 vs 교사용)
- 학생이 보는 모든 곳(앱 제목·목록 행·선택 화면·기록 화면·정답 링크 페이지)에는 H-K코스라고 쓰지 않고 '핵심 7문장 분석 (기본)'이라고 쓴다. 학생은 K·S를 모른다. 예: '3과 핵심 7문장 분석 (기본)', '청석고1 4과 핵심 7문장 분석 (기본)'.
- 'H-K코스'는 선생님끼리 부르는 내부 이름(파일·스킬·대화)에서만 쓴다. 심화는 '핵심 7문장 분석 (심화)'(내부명 H-S코스).
- 새로 만들 때 build 결과의 제목·헤더·rec-h·목록 행을 모두 점검해 'H-K' 글자가 학생 화면에 남지 않게 한다.

## 작업 전
- 원본 앱을 실제로 열어 본다(흉내 내서 새로 만들지 않는다): https://nolbada.github.io/via/vsignal-e/ (저장소 nolbada/via 의 vsignal-e/index.html). 원본은 읽기 전용.
- 필요한 자료를 먼저 말한다: 학교·과, 핵심 문장(영문), 좌본문우해석의 슬래시 조각과 해석.

## 만드는 법
1. build_hk.py 의 D(문장 데이터)와 GQ(절 종류·형식)를 새 과 문장으로 바꾸고 경로도 바꾼다.
2. 청크 {t(영어), r(역할), k(뜻), c, a, g, alt}. 동사 덩어리(be going to V, have p.p., be p.p., be -ing, 조동사+동사)는 한 덩어리.
3. 형식: 자동사+전치사(turn to, persist in)는 1형식+전치사구, confine A to B 는 3형식, It wasn't until A that B 는 강조구문(that 뒤가 뼈대).
4. GQ: 절 청크 번호(ci), 절 종류(명사절/형용사절/부사절)와 세부(주격 관계대명사, 시간, 이유, 양보, 동격, 계속적 용법 등), 뼈대 형식 fm. 준동사는 H-K에서 다루지 않는다.
5. 흐름: 뜻·성분 → 어순 쌓기 → [꾸밈말 '가림' 테이프, 뼈대만 노랗게] → 이 뼈대는 누구와 닮은꼴인가(1~5형식 카드, 짝짓기) → 절이 저절로 펼쳐짐 → 절 종류 → 세부 종류 → 다음 문장. 7문장 후 5문제 마무리 퀴즈.
6. 화면 문구: V시그널 표지·'V SIGNAL' 글자 제거. 결과는 '3과 핵심 7문장 분석 완료'처럼 담백하게. 시작 화면에 '이어서 하기'/'처음부터 다시 하기'. 앱은 고르기만, 쓰기는 종이.
