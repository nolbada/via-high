# 요약문 완성 (정답·해설 앱 + 활동지 PDF)

본문 구간마다 요약문 1개를 만들고 (A)(B) 두 칸에 들어갈 말을 오지선다로 고른다. 3과 6~7문항, 4과도 구간별 1문항. 학평 요약문 유형을 닮게 한다.

## 시작 전에 필요한 원본
- 과 본문 영어·한글(sentences.json), 구간 나누기, 지난 시험지에 요약문이 나왔다면 그 형식.

## 데이터 형식 (scratchpad/y/data.py → 스크립트 zip의 요약문/data.py)
문항 dict: title, sec, rng(문장 인덱스 구간), summary(영어, (A)(B) 빈칸), ko, opts 5개[(A말,B말)], ans, gloss(보기 단어 한글 뜻), ev(근거: 칸, 문장 인덱스, 근거 구, 설명), wrong(오답 해설), note(흐름 한 줄).
- 근거 문장은 sentences.json 인덱스로만 참조한다(직접 타이핑하지 않는다).
- 보기 5개: 두 칸 모두 그럴듯하게. 한 칸만 바꾼 함정, 두 칸을 바꿔 쓴 함정, 방향이 뒤집힌 함정을 섞는다. 정답 번호가 ①~⑤에 고르게 분포.

## 정답·해설 앱 (yoyak.html)
- 문항 카드, 보기 누르면 확인(단일 선택은 즉시 확인 가능). 해설은 본문 근거 문장(영어+한글)과 보기 한글 뜻 중심으로 간결하게.
- 영어에는 항상 한글 뜻. 오답 해설은 짧게.

## 활동지 PDF (학생용, 종이)
- A4 앞뒤 한 장. 한 면을 좌우 2등분(2단, 가운데 점선). Noto Sans CJK KR 10pt 기준(맑은 고딕 크기 기준). hwpx는 한글에서 깨질 수 있어 PDF로 만든다(Playwright page.pdf).
- 요약문 아래에 학생이 해석을 직접 쓸 공간을 넉넉히(줄간격 넓게). 요약문과 오지선다 사이에 여백. 보기 사이 간격도 넓게(다닥다닥 붙지 않게).
- CSS 기준: `@page{size:A4;margin:9mm 10mm 7mm}`, body 10pt line-height 1.5, 요약문 박스 `.sm` line-height 2.5, 보기 `.op` margin 4px 0 line-height 1.5. 스크립트 요약문/pdf_mk.py.
- 파일 이름 앞에 YYMMDD. PC 폴더 261018_요약문_완성/ 에 둔다(결과물 한 부).

## 검수
- 정답 어구가 근거 문장에 그대로 있는가, 보기 5개 중 정답 1개, 오답이 정말 틀린가(두 칸 모두 점검), 앞뒤 면 인쇄 확인(PDF 이미지로 눈으로 확인).
