# 학생 앱 3탭 설계 (주성고2 기준, 다른 학교·학년에 그대로 복제)

작성: 261019 / 위치: `h/<학교>/index.html` 한 파일 + `parts.js` + 활동 페이지들

## 1. 한 줄 요약
학생이 자기 폰에서만 진도를 관리한다. 선생님은 진도표·열기코드를 만지지 않는다.
아래 3탭, **오늘의 학습이 항상 첫 화면**.

| 탭 | 역할 |
|---|---|
| 원문 | 좌본문 우해석 (문장 해석 / 문법 분석 / 주요 문장). 교과서는 문법 분석 없음, 모의고사만 |
| 답안지 | 출처별 접히는 토글. 새 답안지는 목록(KEYS)에 한 줄 추가 |
| 오늘의 학습 | 큰 흐름(주차) → 달력(월~일, 이번 주 줄 강조) → 오늘의 DAY 1장 → 전체 배정표(접힘) |

## 2. 오늘의 학습 구조 (index.html의 today()) — 달력이 기본 화면
- 맨 위 "기말고사 (12/1)" → **달력**(월화수목금토일, 일요일 맨 끝). 이번 주 줄 전체 강조.
- 수업 날짜(월·수·토)에는 테두리 + 진행 색: 테두리만 = 아직, 연한 색 = 일부 했어요, 진한 색+✓ = 모두 했어요.
- 날짜를 누르면 그날의 **DAY 카드**(번호 1~8 활동)가 아래에 열린다. 오늘이 수업 날이 아니면 가장 가까운 지난 수업 날이 선택된다.
- 다 못 했으면 같은 카드로 이어서 한다(진행은 카드 단위로 저장). 더 빨리 하고 싶은 학생은 미래 날짜를 눌러 먼저 해도 된다. 잠금 없음.
- 날짜가 지났는데 안 했으면 "밀림" 표시(잠기지 않음). 일정은 학교마다 다를 수 있어 "권장".
- 달력 아래 "시험까지 큰 흐름"(ROAD 6줄).
- 문구 규칙: "한 칸" 같은 모호한 표현 금지 → "끝난 활동은 체크 표시가 되면서 진하게 바뀌어요". "도장" 금지.

## 3. 활동 8가지와 순서 (스며드는 순서)
1 어휘 → 2 TF → 3 어법선택 → 4 한글 순서(선택) → 5 ABC 순서 → 6 문장삽입 → 7 어색한 곳 → 8 빈칸추론
- 이유: 쉬운 확인(어휘·TF)에서 시작해 구조 → 글 흐름 → 추론(가장 어려운 빈칸) 순.
- 표시: 한글순서는 (선택). 한글순서·ABC·문장삽입·빈칸추론 = "매번 다른 문제", 나머지 = "1회성".
- 동사형·좌본문우해석 등은 일정에서 뺌(나중에 ACT에 한 줄 추가하면 끼워짐).

## 4. 데이터는 index.html 안의 표 3개만 고치면 된다
- `ROAD`: [시작, 끝, 제목, 설명] 주차별 큰 흐름
- `VIS`: 주차별 DAY 3개. `{L:n}`=교과서 덩어리 n, `{D:n}`=모의고사 묶음 n, `t`(제목) `s`(범위) `x`(수업 안내)
- `DOFF=[0,2,5]`: DAY의 요일(월·수·토). 학교 수업 요일에 맞게 변경
- `KEYS`: 답안지 탭 토글 [{g:대분류, subs:[{t:소분류, items:[[이름,설명,주소,진도키]]}]}]
- 활동 주소는 `SEC`(교과서/모의고사별 url), 활동 목록 순서는 `ACT`

## 5. 덩어리(part) 계약 — parts.js
- 모든 활동 페이지는 `?part=N`을 받아 그 범위의 지문/문제만 쓴다. 없으면 전체.
- 교과서 4과: 1=본문 ❶❷❸, 2=❹❺, 3=❻❼ (L4 폴더)
- 모의고사: 1~10 = 1회독(하루 3지문), 11~15 = 2회독(하루 6지문) (mock 폴더)
- 진행 기록 키: `<구간>p<번호>:<활동>` 예) `L4p1:voc`, `mockp12:abc`. 답안지 확인 키: `key:L4:awk`
- 저장은 학생 기기 localStorage(`vhp:<학교>`) — prog.js의 PG.mark/get. 서버·코드 없음.
- SX 앱(ko/abc/mun/blank)은 sx-data.js 로드 직후 shim으로 passages를 inPart 필터하고 DATA.set을 partKey로 바꿈. sx.js는 건드리지 않음.

## 6. 주성고2 현재 일정 (한 학교 예시)
- 1주 10/19~25 교과서 4과 3덩어리 (DAY1 월 ❶~❸, DAY2 수 ❹~❺, DAY3 토 ❻~❼)
- 2~4주 10/26~11/14 모의고사 1회독(하루 3지문: 22년 11월 10개 → 23년 11월 14개 → 24년 10월 6개, 연도 안 섞음)
- 5주 11/16~22 1회독 마무리 + 2회독 시작(하루 6지문, 수업에서 기출 풀이)
- 6주 11/23~28 2회독 + 기출 + 최종정리(28일 토). 11/30(월) 시험 전날은 아직 미배정
- 모의고사 범위 30지문: 22년 11월 29~38 / 23년 11월 21·23·30~41 / 24년 10월 22·23·24·29·30·33 (도표·안내문 제외)

## 7. 다른 학교·학년에 복제할 때
1. 폴더 복사 후 `ROAD`/`VIS`/`DOFF`/`SEC`/`KEYS`와 parts.js의 지문 id만 교체
2. 교과서 단원이 여러 개면 `L4` 구간을 단원별로 늘림(`L3p1` 식 키). 학교마다 진도 순서가 달라도 학생이 아무 DAY나 먼저 할 수 있어서 일정표 수정 불필요
3. 모의고사 회독 수는 지문 수 ÷ 하루 분량으로 계산 (분석·해석까지 하는 1회독은 3, 앱만 하는 2회독은 6)
4. 학교별 따로 주소. 전체 학교 모음 페이지 만들지 않음. 학생 명단·개인 링크는 공개 저장소 밖(구글 시트)
5. 고1·중등은 구조는 같고 활동 목록(ACT)과 달력 시작 요일만 다를 수 있음. 중등은 달력형 첫 화면 동일

## 8. 알려진 한계 / 다음 할 일
- 주성고2 모의고사 쪽 어휘·TF·어색한 곳·어법선택은 아직 없음(칸 숨김). 이그잼포유 공식 자료가 있을 때만 채움
- 4과 어휘 단어장이 ❺까지라 덩어리 3은 대화문 단어만
- 경계에 걸친 문제는 한 덩어리에만 배정(어색한 곳 3번 문제 등)
- 11/30(월) 칸, 26년 기출(추후 공지) 칸은 내용 확정 후 채움
- 답안지 탭: 모의고사 연도별·플러스 자료는 비어 있음
- 예상문제(오지선다) 정답지는 금천·청석·주성고1에만 있고 주성고2는 아직 없음

## 추가 확정 (261019 오전, 모든 학생 공통으로 고정)
- 요일 선택 없음. 날짜는 월·수·토 고정이며 카드에는 "추천일"로 작게 표기, 제목은 "DAY n". 요일이 달라도 DAY 순서대로 하면 됨.
- "밀림" 표시 없음. 한 주(월~일)에 안 끝낸 활동이 있으면 일요일에만 주황 안내(남은 활동 수·DAY).
- 달력은 네모 테두리 없이 점 표시(수업 날 비움 / 일부 반 / 모두 꽉), 선택한 날은 파란 원, 오늘은 "오늘" 글자, 이번 주는 연한 띠.
- 달력 아래 "n주차 한눈에" 표: 가로=그 주 DAY 3개, 세로=8개 활동, 칸=문항 수(완료 ✓). 문항 수는 CNT 표에 실측값을 넣어 둠(활동 페이지를 열어 센 값, 문제 구성이 바뀌면 다시 셀 것).
- 학습 기록 카드(인증샷용): 마지막으로 끝낸 활동·시각 / 다음 활동 / 전체 진행 / 캡처 시각 + "다른 기기예요 · 기록 옮기기"(학생이 DAY·활동 번호를 골라 그 앞을 체크).
- 걸린 시간: parts.js 가 PG.mark 를 감싸 활동 완료 때 "걸린 시간"을 띄우고 localStorage(vhd:키)에 저장, 카드에 "했어요 ✓ 3분". 화면이 보이고 최근 60초 안에 입력이 있었던 시간만 합산, 이어풀기 시 누적. 어휘 퀴즈는 자체 계산(window.NOTIMER=1).
- 어휘 퀴즈(L4/vocab.html, 매번 다른 문제): ①단어 쌍 관계(비슷한/반대/관련 없음, 영어만 보여 주고 뜻은 푼 뒤) ②다의어(교과서 문장에서 파란 단어와 같은 뜻으로 쓰인 문장 고르기, 제출 후 뜻 공개). 이그잼포유 WORDS의 유·반의어 47개·다의어 16개만 사용, 대화문 단어 제외, 영영풀이·예문 빈칸 사용 안 함. 시작 시 전체/20/10 선택, 한 문제씩 제출→확인→다음, 이어풀기.
- 학생 화면 용어: "덩어리" 대신 "본문 n"/"이번 범위".

## 추가 확정 2 (청석고2·금천고2 / 오답 노트)
- 청석·금천: 4과 4회(본문 ❶❷/❸❹/❺/❻❼) → 3과 4회 → 모의고사 10회 → 최종정리 3회(11/30, 12/2, 12/5). 월수토 고정, 3과·모의·최종정리는 "준비 중".
- 시험 기간은 달력에 빨간색(EXAMD). 주성 12/1~12/4, 금천 12/7~12/10, 청석 12/7~12/11.
- 오답 노트: 학교별 wrong.js(WN)·wrong.html. localStorage `vhw:<학교>`, 항목 id = kind:part:act:qid.
  활동에서 틀리면 자동 담김(멱등, 맞혀도 자동 삭제 없음). 학생이 「빼기」(두 번 눌러 확인)로만 제거.
  `?wrong=1&part=N` 모드 = 담긴 문제만 다시 풀기(진도 체크·걸린시간 기록 안 함, 이어풀기 키 `:w` 분리).
- 순서배열·빈칸은 qid = 지문 id, find = 소단락 번호, awk = 문항 id, 어휘 = 단어 쌍/다의어 id.
- find(다른 문장 찾기)는 제출 버튼이 없어 "같은 문장을 눌렀는데 다른 문장을 다 못 찾음" 또는 "해설 모두 열기"를 오답으로 처리.
- 새 학교 추가 시 wrong.js·wrong.html 복사(학교명만 치환) + L4/mock 페이지 훅 포함.
