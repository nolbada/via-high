# 고등 답안지 탭 만들기 (261019)

## 한 줄 요약
답안지 탭은 **출처(교과서 3과·4과, 모의고사, 플러스 자료) 토글** 안에 정답 페이지를 **정해진 순서**로 넣는다. 새 답안지는 `KEYS` 에 한 줄 추가.

## 필요한 것
- 정답이 들어 있는 hwpx(어법선택·동사형·Check·빈칸 영어·빈칸 우리말), 예상문제 1~4회 정답, 내용정리 플러스(요약문).
- 견본 폴더: `h/jusung-go1/L4/` (hangeul·eobeop·dongsa·check·yeongeo·yesang1~4·yoyak·hk·hs).

## 하는 일
1. **기본 순서(모든 학교 공통)**: 빈칸 우리말 → 어법선택 → 동사형 → Check → 빈칸 영어 → 예상문제 1~4회. 플러스 자료 토글에는 요약문, 핵심 7문장 분석(기본)/(심화).
2. 어색한 곳 찾기는 답안지에서 **뺀다**(앱 학습 영역에 있다).
3. **토글은 한 단계만.** 출처가 곧 토글이다: `교과서 3과` / `교과서 4과` / `모의고사` / `플러스 자료`. 그 안에는 정답 항목이 바로 나온다(그 아래에 또 "3과"·"4과" 토글을 두지 않는다). 플러스 자료는 항목 이름 앞에 "3과 "/"4과 "를 붙인다. 모의고사처럼 연도 구분이 진짜 필요한 곳만 하위 토글(`t:'22년 11월'`)을 쓴다. 구조 `KEYS=[{g:'교과서 3과',subs:[{t:'',items:[[이름,설명,주소,'key:L3:dongsa']]}]}]` — `t:''`이면 하위 토글 없이 항목만 나온다.
4. 모든 정답 페이지 꼴: **빠른정답**(번호 배지 + 빨간 정답 칩 + 한글 뜻) → 문항 카드. 맨 아래 「답 확인했어요」(`PG.bar('key:L?:…')`) → 확인한 항목은 진하게.
5. 정답은 hwpx 공식 정답과 전수 대조한다. 영어에는 한글 뜻을 붙인다. 해설은 사전식 뜻풀이가 아니라 문장 흐름·앞뒤 연결 위주.
6. 동사형: be going to + 동사원형, have p.p., be p.p., be -ing 같은 한 덩어리 동사는 한 칸으로 묶는다. 교과서가 축약형(Here’s)이고 공식 정답이 풀어 쓴 형태면 공식 정답을 따르고 사람이 볼 곳으로 보고한다.
7. 예상문제는 영어 보기에 한글 뜻(괄호), 근거 문장에 한글 해석. 마지막에 누락 검수.
8. 시험 범위가 아닌 본문 외 지문은 뺀다(보고에 적는다).

## 끝났다는 신호
- `KEYS` 의 모든 주소가 실제 파일로 열린다(스크립트로 전부 확인).
- 모든 학교가 같은 순서로 보인다.

## 하지 말 것
- 순서를 학교별로 바꾸기. 주소가 빈 항목(`''`)을 올린 채 두기.
- 모의고사 정답을 내용 없이 만들어 두기(비어 있으면 토글을 "준비 중"으로).
