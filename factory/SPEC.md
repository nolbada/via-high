# 학교 앱 규격 (기준: geumcheon-go1)

## 회 번호
- 전체 연번. 표기 "N회 (소속)". 시험까지 큰 흐름도 같은 연번.
- geumcheon/cheongseok go1: 3과 1~4, 4과 5~8, 모의고사 9~18, 최종점검 19~21
- geumcheon/cheongseok go2: 4과 1~4, 3과 5~8, 모의고사 9~18, 최종점검 19~21
- jusung-go1: 4과 1~2, 3과 3~6, 모의고사 7~15, 최종점검 16~19 (총 19회)
- jusung-go2: 4과 1~3, 모의고사 4~13, 기출 복습 14~15, 교과서 기출 16~18, 최종점검 19
- 날짜는 항상 요일 포함: 10/6(화)

## 화면 (위에서 아래)
1. 이어서 풀기 카드 (책갈피 있을 때만)
2. 오답 노트 / 랜덤 문제 풀기 카드
3. 기말고사 날짜 줄, 이번 주 목표 3회
4. 달력 (완료한 회가 있는 날 표시, 날짜 누르면 그날 학습 기록)
5. 유형 풀코스 · N회 (소속): 유형 줄 8~9개
   - 줄 왼쪽: 안 한 것 연한 회색 체크박스, 끝나면 같은 칸이 파란 ✓
   - 주황 "풀기" 박스 금지. 유형 이름을 누르면 열림
   - 전체 선택 / 전체 해제, "체크한 유형 이어서 풀기 (N)" 버튼
6. 이전 회 / 다음 회
7. 내 학습 기록 (인증샷용): 제목 "오늘의 학습 · 10/22(목)", 회별 머리글 "N회 (소속)  소요 N분 ›", 작은 번호 배지 줄. 머리글 누르면 그 회로 이동. "마지막으로 끝낸 활동" 문구 없음. 유형별 소요시간 없음.
8. 시험까지 큰 흐름: 주차, 날짜(요일 포함), 해당 주 회 범위와 소속

## 금지
- 학생 화면에 사용법 안내 문구, 이모지, 학원명 노출 (푸터 "비타민 영어클리닉"은 유지)
- 일반 외부 링크로 새는 요소

## 동작
- 회 완료 = 유형 풀코스 기준. 한글 순서배열은 선택
- 이어서 풀기: 푼 페이지 책갈피(vhbm:학교), 체크한 유형 큐(vhq:학교), 다음 유형 바
- 기록 키: PG(vhp:학교) / 소요시간 vhd:키 / 완료일 vhc:학교
- 활동 키: L4p1:voc, L3p1:find, mockp4:abc, Fp1:wk
- 오답 노트: 1회 오답 담김, 2회 오답 별표

## 수치
- SPEC_values.md 참조. 색은 학교 테마 변수(--pri, --onpri)를 쓰고 값은 학교마다 달라도 됨.

## 새 영역 추가 규칙 (모의고사 확장, 해설서 추가 등)
1. 기존 회 번호는 절대 재배열하지 않는다. 학생 기록(PG, vhc, vhd)이 번호로 저장되므로 번호가 밀리면 다른 회로 바뀐다. 새 회는 맨 뒤 번호로만 추가한다.
2. 새 활동 키는 mockp번호:유형 형식을 따르고, 기존 키 이름은 바꾸지 않는다.
3. common/prog.js는 6개 고등 학교와 기말 앱 3개가 공유한다. 새 영역 때문에 고쳐야 하면 먼저 영향 범위(9개 앱)를 알리고, 가능하면 학교별 파일이나 별도 파일에 둔다.
4. 풀코스에 유형을 추가하면 mix-pool.js도 같은 작업에서 갱신한다. 풀코스와 풀이 어긋나지 않는지는 audit 항목으로 검사한다.
5. 읽는 형태(해설서 등)처럼 문제를 푸는 페이지가 아닌 것은 회 완료 판정 기준을 따로 정해 SPEC에 적은 뒤에 넣는다. 정하기 전에는 완료 판정에 포함하지 않는다.
6. 새 영역을 넣은 뒤에는 6개 학교 audit.py를 모두 돌려 PASS일 때만 반영했다고 말한다.
