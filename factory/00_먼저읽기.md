# 공장 기준 폴더 (factory)

이 폴더 하나가 "학교 앱 기준"의 전부다. 기존 학교 앱 파일(h 폴더 등)과 섞이지 않는다.
다른 PC나 다른 선생님께 넘길 때는 이 폴더만 주면 된다.

## 받는 사람이 할 일
1. 이 폴더를 통째로 받는다. 저장소 전체 필요 없음: https://github.com/nolbada/via-high/tree/main/factory
2. pip install playwright 그리고 playwright install chromium (처음 한 번)
3. 실제 사이트 검수: python3 tools/audit.py --live
   - PASS 면 6개 학교가 기준과 같다. FAIL 이면 줄마다 어디가 다른지 나온다.
4. 학교 파일을 직접 고치는 작업(포팅)은 저장소 전체를 받아 factory 가 저장소 안에 있을 때만 된다.

## 파일 안내
- SPEC.md : 기능·문구·회 번호 규칙
- SPEC_values.md : 크기·색 수치
- snippets/ : 기준 코드 조각
- tools/ : 포팅 도구와 audit.py (검수)
- README.md : 명령어 요약

## 지킬 것
- 기준을 바꾸면 SPEC과 snippets 부터 고친다.
- "반영했다"는 말은 audit.py PASS 후에만 한다.
