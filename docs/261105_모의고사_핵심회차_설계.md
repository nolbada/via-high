# 모의고사 핵심 회차 설계 (금천고2 25년 10월에서 확정, 261105)

다른 학교·다른 시험(예: 주성고2, 26년 10월 고1)에도 같은 방식으로 만든다.

## 1. 회차 구성
- 시험 범위 지문을 5개 안팎씩 덩어리로 묶는다 (금천고2: 20-24 / 29-33 / 35-40번).
- 덩어리마다 "핵심 1회" 15문항 + 일반 1~3회. 전체 지문에서 한 문항씩 모은 "종합 핵심 1회"와 종합 1·2회도 둔다. 핵심은 모두 4회.
- 핵심 우선순위: 빈칸·순서·삽입 > 요약 > 어법·어휘 > 무관한 문장 > 주제·제목 > 요지·주장·함축 > 내용일치 > 목적.
- 나머지 회차는 1회 → 3회로 갈수록 덜 급한 문항 (쉬운 문제라는 뜻이 아님. 시간 없을 때 앞부터 풀면 되게).
- 핵심에 들어간 문항은 다른 회차에서 뺀다(중복 없음).

## 2. 이름
- 덩어리 이름은 번호 범위 그대로(예: 20-24번). 전체 묶음은 출처 이름을 넣는다(예: 너른터·아잉카·비밀노트·쏠북·이그잼포유 종합).
- 파일·폴더 이름 앞에 날짜(YYMMDD).

## 3. 앱 답지 목록 분류 (아코디언 3개)
1. 유료 기출자료: 핵심 4개 → 덩어리 회차 → 종합 회차 (이번에 만든 것만)
2. 학교 기출: 실제 학교 기출 회차
3. 워크북 활동: 빈칸 우리말 / 어법 선택형 / 동사형 / 빈칸 영어

## 4. 해설 페이지 (학생용)
- 번호 배지 + 빨간 정답 칩 빠른정답, 번호 누르면 해설로 이동.
- 영어에는 항상 한글 뜻, 근거 문장에는 해석, 지문 내용 정리·글의 흐름·꼭 기억할 낱말은 지문당 한 번.
- 초등 6학년에게 짚어 주듯 쉬운 말투.
- 만든 뒤 반드시 Opus로 누락 검수(학생들이 "중간중간 답이 없어요"라고 신고한 적 있음).

## 5. 저장 위치
- 해설: 깃허브 via-high/h/<학교>/mock/key/ + 목록(index.html)
- 문제지 PDF: 컴퓨터 `3 시즈널 출력실\<시즌 폴더>\` (교과서가 아니라 시즌 자료)
- 예전 자료는 `3 시즈널 출력실\delete\` 로 모아 나중에 폐기.

## 6. 목록 고칠 때 주의
- index.html의 KEYS 목록은 괄호 하나만 틀려도 학생 화면에 "화면에 오류가 났어요"가 뜬다. 고친 뒤 반드시 문법 검사 후 올린다.
